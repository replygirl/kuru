## Why

Users can select Kuru's native ChatGPT subscription route without a public
description of its fixed compatibility values, support limits, or logout scope.

## What Changes

- `apps/kuru-docs/guide/authentication.md`: document the fixed compatibility
  contract, separate API-key access, local logout, and update procedure.
- `docs/protocols.md`: link provider behavior to the same contract and existing
  literal fixture coverage.

## Impact

Readers can assess the native subscription route without implying OpenAI
support, remote revocation, or another runtime dependency.
