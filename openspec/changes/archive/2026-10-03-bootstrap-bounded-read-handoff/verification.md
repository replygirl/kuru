# Verification

## 1. A bounded call cannot stall waiting for end of file [critical]

- [x] 1.1 @regression (agent) `bounded_reads_install_through_the_mirror_without_a_fifo_handoff` (mirror case, hostile fixture `mkfifo` whose FIFOs cannot be opened for writing), run with the original and the fixed `install.sh` -> Observed 2026-10-03, macOS arm64: original fails at the fixture's 30 s bound (`capture_elapsed_ms=30002`, `root=running`, stage `stream` present, stderr `stream: Permission denied`); fixed passes and installs without invoking `mkfifo`, with three requests.
- [x] 1.2 @runtime (agent) scratch Bash 3.2 harnesses on macOS arm64 (14 cores, six `yes` loads, eight concurrent harnesses), a call counted stalled when `head` is still alive 12 s after its producer was reaped -> Observed 2026-10-03, permanent stalls with `head` blocked in `read()` on the FIFO: original protocol 2/10000 empty producers and 0/10000 data producers in the final matched run (earlier runs 3/2000, 4/4000, 8/4000 empty, 1/3000 data with the 12 bytes consumed); bootstrap-opens-every-end variant 2/10000 empty and 0/30000 data in that run (0/60000 across earlier runs); same variant unlinking the FIFO early 1/20000 and 2/6000 data; anonymous pipe `producer | head` 0/20000. The kernel mechanism is not isolated: XNU `fifo_vnops.c` (read, close and open paths) shows no path that loses end of file.
- [x] 1.3 @runtime (agent) end-to-end loop of the real bootstrap against a local release (six bounded calls per run) under the same load, a run counted stalled when alive after 10 s -> Observed 2026-10-03: original 3/6000 runs stalled (`head -c 65537` alive with `stream` present: twice on the `SHA256SUMS` fetch, once on the archive type listing); fixed 0/6000.
- [x] 1.4 @unit (agent) Bash 3.2 file-size limit probes -> Observed 2026-10-03: `ulimit -f 64` writes fill to 65536 bytes and the producer exits 153; exactly 65536 bytes exit 0; a producer that writes 65537 bytes then sleeps is stopped at once with 153; with SIGXFSZ ignored it exits 1 (`File too large`); `/bin/sh` (POSIX mode Bash 3.2) also counts 1024-byte blocks; an inherited 100-block hard limit below a 128-block cap is kept through `ulimit -S -f hard` and still stops the producer; `wait` with stderr discarded suppresses the shell's job message.
